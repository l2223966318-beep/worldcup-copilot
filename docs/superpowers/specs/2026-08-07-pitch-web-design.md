# WorldCup Copilot 决赛答辩网页设计说明

## 目标

为腾讯会议屏幕共享制作一个独立的全屏答辩网页。页面需要在五分钟内清楚说明项目背景、核心机制、产品闭环和创新价值，同时能够一键进入真实系统演示。

该页面是展示层，不改变赛事数据、热点、AI 生成、审稿或导出业务逻辑。

## 路由与边界

- 新增独立路由 `/pitch`。
- 页面采用固定全屏容器覆盖现有站点 Header 和悬浮助手，不修改全局布局。
- 不接入实时接口，答辩页只使用经过确认的产品截图和项目事实，避免现场网络波动影响讲述。
- “进入产品实机”和“经典案例”按钮跳转现有页面，不复制业务功能。
- 不引入新的动画、演示或幻灯片依赖。

## 视觉方向

- 参考现有个人作品集的编辑式案例排版，不复制具体页面。
- 主色为球场黑、深草绿、暖白和金色，橙色仅用于信号线和强调。
- 使用大字号标题、细线网格、非对称截图拼贴和整屏章节构图。
- 避免纯蓝满版、圆角卡片堆叠、电竞霓虹和复杂粒子。
- 动效控制为 220-420ms 的淡入、轻微位移和章节切换，并支持 `prefers-reduced-motion`。

## 章节结构

1. **封面**：WorldCup Copilot、赛事信号成为内容资产、B站内容运营相关实习背景、进入答辩。
2. **项目起点**：信息分散、选题依赖经验、审核成本后置；明确为个人实践项目，非B站官方项目。
3. **系统逻辑**：赛事数据、价值判断、选题生成、平台适配、证据审校。
4. **内容机会判断**：展示比赛机会等级、维度评分及评分依据，强调“评分依据比总分更重要”。
5. **AI 选题引擎**：先生成作品角度，再按 B站、微博、小红书、公众号形成不同交付物。
6. **发布审校与交付**：具体风险句、证据支持、改写建议和 Word 报告。
7. **结论**：先取证、再生成、后审校；提供进入真实系统和经典案例入口。

## 交互

- 鼠标滚轮、触控板和键盘上下键切换章节。
- `Home` 跳到首屏，`End` 跳到结尾，数字键 `1-7` 直达章节。
- 右侧显示章节进度点，底部显示当前页码和下一页提示。
- 顶部提供退出答辩、进入系统和全屏按钮。
- 页面按钮必须真实可用，链接到 `/`、`/matches/argentina-france-2022-final` 和浏览器全屏 API。
- 滚轮切换增加短暂节流，避免触控板一次跳过多页。

## 文件

- `app/pitch/page.tsx`：章节内容、状态、键盘与全屏交互。
- `app/pitch/pitch.css`：答辩页独立视觉、章节切换和响应式样式。
- `public/pitch/`：球场背景及九张产品截图。

## 响应式与可访问性

- 以 16:9 桌面共享为主要画布，兼容 1366×768、1440×900 和 1920×1080。
- 小屏改为纵向滚动阅读，不强制一屏塞下全部信息。
- 交互按钮有可见焦点，所有图片提供替代文本。
- 尊重系统减少动态效果设置。

## 验证标准

- `npm.cmd run build` 通过。
- 1366×768 和 1920×1080 下无文字、截图或导航重叠。
- 键盘、滚轮、进度点、全屏、退出和实机链接均可用。
- 页面首次打开即可看到产品名称、核心价值和实习背景。
- 所有展示文字均为项目现有能力，不编造赛事数据、用户数据或B站官方背书。
