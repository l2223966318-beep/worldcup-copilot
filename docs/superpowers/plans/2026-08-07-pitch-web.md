# WorldCup Copilot Pitch Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-ready `/pitch` route for five-minute Tencent Meeting screen-share presentations.

**Architecture:** Add an isolated client presentation page that covers the existing application shell with a fixed full-screen stage. Store slide content as typed data, keep navigation and full-screen behavior in the page component, and scope all visuals to one route stylesheet.

**Tech Stack:** Next.js App Router, React 18, TypeScript, CSS, lucide-react.

## Global Constraints

- Do not modify existing business logic or data structures.
- Use seven full-screen chapters and real links to `/` and `/matches/argentina-france-2022-final`.
- Use stadium black, pitch green, warm white, gold and signal orange; no pure-blue full screens.
- Keep motion restrained and respect `prefers-reduced-motion`.
- Reuse existing screenshots and visual assets; do not invent product metrics or Bilibili endorsement.
