# WorldCup Copilot 核心源代码节选

以下为项目核心功能的脱敏节选，用于说明系统如何完成赛事信息处理、传播价值评分、多平台内容生成、证据审稿和 Word 报告导出。

## 1. 热点传播价值评分

来源文件：`lib/hot/valueScoring.ts`

功能说明：把热点条目转成 0-100 的传播价值分，综合考虑热度、赛事相关性、时效性、内容潜力和风险扣分。

```ts
export function scoreHotItem(item: HotItem): HotValueBreakdown {
  const text = `${item.title} ${item.summary ?? ""} ${(item.tags ?? []).join(" ")}`;
  const normalized = normalize(text);

  const heatScore = getHeatScore(item.heat ?? item.hot, item.rank);
  const relevanceScore = getRelevanceScore(normalized);
  const timelinessScore = getTimelinessScore(item.publishedAt ?? item.time);
  const contentPotentialScore = getContentPotentialScore(normalized);
  const riskPenalty = getRiskPenalty(normalized);

  const weakSports = relevanceScore < 12;
  const cappedHeatScore = weakSports ? Math.min(heatScore, 12) : heatScore;
  const valueScore = clamp(
    cappedHeatScore + relevanceScore + timelinessScore + contentPotentialScore - riskPenalty,
    0,
    100
  );

  return {
    heatScore: cappedHeatScore,
    relevanceScore,
    timelinessScore,
    contentPotentialScore,
    riskPenalty,
    valueScore,
    valueLevel: getValueLevel(valueScore),
    category: classifyCategory(normalized),
    tags: buildTags(normalized, getValueLevel(valueScore))
  };
}
```

对应产品能力：右侧“今日热点雷达”和比赛详情页“场上热点信号”会按价值分排序，帮助运营优先处理更值得做内容的热点。

## 2. 多平台内容生成

来源文件：`lib/ai/platform-draft.ts`

功能说明：用户选择平台、生成类型和风格类型后，系统将比赛事实、证据包和热点信息传给 AI，生成平台化内容。

```ts
export async function generatePlatformDraftWithAi(input: {
  platform: PlatformKey;
  contentType: ContentTypeKey;
  topicMode: TopicModeKey;
  matchContext: MatchContext;
  topic: WorkflowTopic;
  analysis: AnalysisResult;
  apiKey?: string;
}) {
  const generationTask = input.contentType === "topic"
    ? buildTopicAngleTask(input)
    : buildPlatformDraftTask(input);

  const result = await generateDeepSeekJson<AiPlatformDraft>(
    [
      {
        role: "system",
        content: [
          "你是体育内容运营编辑，只输出严格 JSON。",
          "只能基于输入的比赛事实、事件、数据和热点信号生成。",
          "未出现在 evidence 中的数字，不得写入稿件。",
          "内容要像真实运营稿，短、准、可发布。"
        ].join("\n")
      },
      {
        role: "user",
        content: JSON.stringify({
          platform,
          generationType,
          styleType,
          matchContext,
          evidence: matchContext.evidence ?? [],
          topic,
          analysis
        })
      }
    ],
    { timeoutMs: 24000, apiKey, quality: "quality", reasoningEffort: "high" }
  );

  return normalizePlatformDraft(result, input);
}
```

对应产品能力：多平台分发工作台不是简单改语气，而是按平台结构生成不同内容，例如 B站脚本、微博讨论、小红书图文卡片、公众号复盘等。

## 3. 赛事证据包构建

来源文件：`lib/services/evidenceService.ts`

功能说明：把比分、统计、关键事件和热点来源整理为证据包，并生成 `E01`、`E02` 这样的证据编号，供 AI 生成和审稿使用。

```ts
export function buildEvidencePack(
  matchContext: MatchContext,
  hotspots: EvidenceHotspot[] = []
): EvidenceItem[] {
  const evidence: EvidenceItem[] = [];
  const { matchInfo, stats } = matchContext;

  evidence.push({
    id: "",
    type: "match_stat",
    text: `${matchInfo.teamA} vs ${matchInfo.teamB}，比分 ${matchInfo.score}`,
    source: matchInfo.sourceStatus === "live" ? "Sportradar" : "赛事数据",
    relevance: 100
  });

  if (matchContext.verifiedStats !== false) {
    evidence.push({
      id: "",
      type: "match_stat",
      text: `${matchInfo.teamA}控球率 ${stats.teamA.possession}%，${matchInfo.teamB}控球率 ${stats.teamB.possession}%`,
      source: "Sportradar",
      relevance: 94
    });
  }

  matchContext.keyEvents.slice(0, 10).forEach((event) => {
    evidence.push({
      id: "",
      type: "match_event",
      text: `${event.minute} ${event.team} ${event.description}`,
      source: "Sportradar",
      relevance: event.type === "goal" ? 98 : 90
    });
  });

  hotspots.slice(0, 8).forEach((hotspot) => {
    evidence.push({
      id: "",
      type: "hot_topic",
      text: hotspot.title,
      source: hotspot.source,
      sourceUrl: hotspot.url,
      relevance: hotspot.valueScore ?? 70
    });
  });

  return evidence
    .sort((a, b) => b.relevance - a.relevance)
    .slice(0, 16)
    .map((item, index) => ({ ...item, id: `E${String(index + 1).padStart(2, "0")}` }));
}
```

对应产品能力：内容生成和审稿都不再只依赖模型自由发挥，而是先建立可追踪的事实来源。

## 4. 证据约束风险审稿

来源文件：`lib/services/evidenceService.ts`、`lib/ai/review-draft.ts`

功能说明：审稿时不再泛化地提示“数据需核实”，而是逐句判断哪些事实有证据，哪些句子超出证据范围。

```ts
export function auditDraftEvidence(draft: string, evidence: EvidenceItem[]) {
  const claims = splitSentences(draft)
    .filter(isFactualClaim)
    .map((sentence) => {
      const evidenceIds = findSupportingEvidence(sentence, evidence).map((item) => item.id);
      return {
        sentence,
        supported: evidenceIds.length > 0,
        evidenceIds
      };
    });

  const unsupported = claims.filter((claim) => !claim.supported);

  return {
    claims,
    findings: unsupported.map((claim) => ({
      type: "缺少事实依据",
      sentence: claim.sentence,
      reason: "该句包含具体比分、时间点、事件或统计判断，但证据包中没有直接支持记录。",
      rewrite: "删除该句，或补充可核验来源后再发布。",
      evidenceStatus: "missing",
      evidenceIds: []
    })),
    summary: {
      checkedClaims: claims.length,
      supportedClaims: claims.length - unsupported.length,
      unsupportedClaims: unsupported.length
    }
  };
}
```

对应产品能力：审稿结果会展示风险等级、证据编号、具体问题句和改写建议，便于编辑快速修稿。

## 5. 多源热点汇集

来源文件：`lib/services/matchDetailPresentation.ts`

功能说明：比赛详情页会将外部热点源和场上事件合并，去重后按热度和价值分排序，形成与该场比赛相关的短榜。

```ts
export function buildMatchHotspotShortlist({
  match,
  signals,
  hotItems,
  limit = 8
}: {
  match: MatchData;
  signals: MatchSignal[];
  hotItems: HotItem[];
  limit?: number;
}): MatchHotspot[] {
  const sourceTopics = hotItems
    .map((item) => hotItemToMatchHotspot(item, match))
    .filter((item): item is MatchHotspot => Boolean(item));

  const signalTopics = signals.map((signal) => signalToMatchHotspot(signal, match));
  const deduped = dedupeHotspots([...sourceTopics, ...signalTopics]);

  const sorted = deduped.sort(
    (a, b) => b.heatScore - a.heatScore || b.valueScore - a.valueScore || a.rank - b.rank
  );

  return selectDiverseHotspots(sorted, limit)
    .map((item, index) => ({ ...item, rank: index + 1 }));
}
```

对应产品能力：场上热点信号不只看单一来源，而是汇集比赛事件、微博/B站/小红书等热点源结果，生成可进一步分析或生成内容的热点卡片。

## 6. Word 报告导出

来源文件：`lib/word-export.ts`

功能说明：把 Markdown 内容转换为 Word 文档，用于导出“可直接发布版、编辑参考版、风险提示版、证据与来源”。

```ts
export async function downloadWordReport(filename: string, markdown: string) {
  const blob = await createWordReportBlob(markdown);
  downloadBlob(ensureDocxExtension(filename), blob);
}

export async function createWordReportBlob(markdown: string) {
  const {
    Document,
    Packer,
    Paragraph,
    Table,
    TextRun
  } = await import("docx");

  const blocks = parseMarkdown(markdown);
  const children = blocks.map((block) => renderWordBlock(block));

  const document = new Document({
    creator: "WorldCup Copilot",
    title: blocks.find((block) => block.type === "heading")?.text ?? "内容报告",
    sections: [{ children }]
  });

  return Packer.toBlob(document);
}
```

对应产品能力：用户可以把 AI 生成结果和审稿依据打包成 Word，形成可提交、可复核的内容方案。
